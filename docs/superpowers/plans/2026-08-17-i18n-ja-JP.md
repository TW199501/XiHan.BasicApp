# ja-JP 日文語言包 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 `ja-JP` 成為 XiHan.BasicApp 前端一個完整可用的介面語言，外殼層、業務層與五個可選模組全部顯示自然日文。

**Architecture:** 先用 5 個任務把「管線」打通（建骨架檔、接線、放寬兩個門禁腳本、加切換器選項與 Naive UI 語系），此時日文可選但內容仍是英文；再用 9 個任務逐批把 5,868 行英文翻成日文，每批獨立驗證與提交。翻譯來源是 `en-US`（已由使用者人工對照 `zh-CN` 驗證過），語意不明處回查同鍵的 `zh-CN`。

**Tech Stack:** Vue 3 + TypeScript + vue-i18n + Naive UI + Vite；pnpm workspace；驗證靠 `vue-tsc` 與倉庫自帶的零依賴門禁腳本 `validate-i18n.mjs` / `validate-modules.mjs`。

## Global Constraints

- 所有 pnpm 指令在 `frontend/` 目錄下執行。Node ≥ 24，pnpm ≥ 11。
- 路徑別名：`@` → `frontend/src`，`~` → `frontend/packages`。
- **鍵名、巢狀結構、檔案內順序一律不得更動**，只改值。`validate-i18n.mjs` 要求各語言鍵集完全對稱，動結構即紅燈。
- **佔位符原樣保留**：`{tenant}`、`{count}`、`{name}` 等大括號變數，以及 vue-i18n 的 `@:` 連結語法。
- **不翻譯的技術名詞**：SignalR、OAuth、OIDC、Token、API、JSON、Cron、Webhook、SQL、Redis、AppKey、AppSecret、TOTP、RAG、MCP。
- **後端完全不動**。`backend/src/main/XiHan.BasicApp.WebHost/Localization/` 維持 `zh-CN`/`en-US`。日文介面下列舉標籤與 API 錯誤訊息會回退簡體中文，是本階段的已知限制。
- **未完成的語言不上架**：`zh-TW` / `ko-KR` / `de-DE` 的 import 在 `packages/locales/index.ts` 保持註解狀態。
- 提交訊息用 conventional 前綴，正文用簡體中文（與倉庫既有提交一致），結尾附 `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`。

### 進度驗證腳本（每個翻譯任務都會用到）

**A. 整檔是否仍與 en-US 相同（= 完全未翻）**

```powershell
# 外殼層
$ja='frontend/packages/locales/langs/ja-JP'; $en='frontend/packages/locales/langs/en-US'
Get-ChildItem $en -File | ForEach-Object {
  $j = Join-Path $ja $_.Name
  $state = if (-not (Test-Path $j)) { '缺檔' }
           elseif ((Get-FileHash $j -Algorithm MD5).Hash -eq (Get-FileHash $_.FullName -Algorithm MD5).Hash) { '未翻譯' }
           else { '已翻譯' }
  '{0,-16} {1}' -f $_.BaseName, $state
}
```

業務層把兩個變數換成 `frontend/src/locales/langs/ja-JP` 與 `.../en-US` 即可。

**B. 單檔日文覆蓋率**

```powershell
$f = 'frontend/packages/locales/langs/ja-JP/common.ts'
$vals = Select-String -Path $f -Pattern "^\s+[\w_]+: '"
$jp = $vals | Where-Object { $_.Line -match '[\p{IsHiragana}\p{IsKatakana}\p{IsCJKUnifiedIdeographs}]' }
'值 {0} 行，含日文 {1} 行' -f $vals.Count, $jp.Count
```

來源是英文，所以任何日文假名或漢字都代表該行已翻。少數行合理維持英文（`API`、`JSON`、`OAuth`、純數字、純符號），差額需能逐條說明。

```ts
import jaJP from './langs/ja-JP'
```

```ts
const moduleLocales = import.meta.glob('/src/modules/*/locales/*.ts', { eager: true })

/** 必须在 app.mount() 之前调用，否则首屏会渲染出裸 key */
export function setupBusinessLocales() {
  registerLocaleMessages({
    'zh-CN': zhCN,
    'en-US': enUS,
    'ja-JP': jaJP,

  }
}
```

```ts
import type { NDateLocale, NLocale } from 'naive-ui'
import { dateEnUS, dateJaJP, dateZhCN, enUS, jaJP, zhCN } from 'naive-ui'
import { computed } from 'vue'
import { useAppStore } from '~/stores'

/** locale → naive-ui 语系对象。新增语言在此加一行即可。 */
const NAIVE_LOCALES: Record<string, { ui: NLocale, date: NDateLocale }> = {
  'zh-CN': { ui: zhCN, date: dateZhCN },
  'en-US': { ui: enUS, date: dateEnUS },
  'ja-JP': { ui: jaJP, date: dateJaJP },
}

export function useNaiveLocale() {
  const appStore = useAppStore()
  const locale = computed(() => appStore.locale)

  // 未登记的语言回退英文，避免中文组件文案混进外语界面
  const entry = computed(() => NAIVE_LOCALES[locale.value] ?? NAIVE_LOCALES['en-US'])
  const naiveLocale = computed(() => entry.value.ui)
```
